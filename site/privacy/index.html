Privacy Policy

Last updated: 2 September 2026

This policy covers the Android app Québec French, package com.quebecfrench.app, distributed on Google Play. The same text ships inside the app at Settings → About → Privacy policy.

The short version

Québec French collects nothing. No account, no analytics, no advertising, no tracking, and no server operated by the developer. Review progress stays on your device unless you export it yourself.

What stays on the device

Flashcard progress, the chosen voice, and the theme preference are stored in the app's local storage only. Uninstalling the app deletes them. The optional “Export progress” feature writes a file that you control; nothing is uploaded anywhere.

The one network request

Downloading the optional pronunciation audio pack fetches a file from GitHub releases (github.com). As with any web request, GitHub's servers see your IP address and standard request logs; the app sends nothing else with the request. GitHub's own privacy statement governs their logs. The app makes no other network requests.

Data collection, sharing, and sale

None. The app collects no personal data, shares none, and sells none. There is no third-party SDK for analytics, advertising, or crash reporting.

Children

The app has no chat, no user-generated content, no purchases, and collects no data from anyone, children included.

Changes

If a future version ever changes any of the above, this policy and the in-app copy will be updated before that version ships, and the “Last updated” date will change.
